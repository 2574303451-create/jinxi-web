# 现有身份入口复核

固定 #16 源码并分别核对页面调用与服务端入口。本轮关闭首页的旧登录缓存同步。保留缓存字节，本机游戏记录由独立浏览器 ID 读取，两类浏览器都显示同一份明确标记的本机模式。任务页面读取旧历史时跳过原批量清除，日常任务的日期重置照常执行。

| 页面或模块 | 当前证据与处理 | 真实会话恢复条件 |
| --- | --- | --- |
| 首页导航、成员行动、登录、改密 | 正式旧登录/改密按钮禁用。缓存无法改变导航或锁定改密账号，旧缓存不在页面载入时转换为身份 | 同一服务端会话状态，首登、过期、撤销和本人权限 |
| 本机游戏面板 | 原先用浏览器缓存的 loginAccount 作为入口。现在沿用本机记录及默认示例，入口与账号缓存无关 | 如果以后保存到服务器，单独定义本人授权与数据迁移 |
| 留言、回复、反应、展播 | 留言读取与本机草稿可用，作者输入不受旧账号锁定。旧写接口拒绝 | 会话取作者，匿名历史独立，跨账号修改拒绝 |
| 攻略中心、评论、投稿 | 公开已发布攻略读取，投稿/评论等写入暂停。旧客户端策略页是未接入 scaffold | 公开 DTO 白名单、可信作者、审核及跨账号权限 |
| 签到、排行、兑换、任务 | 页面提示服务端业务暂停。任务为规则参考与本机历史，`claimReward` 返回 false | 真实会话、可信事实、价格和幂等收据逐项验收 |
| 组队 | 本机演示状态，加入和退出仅保存在浏览器 | 真实队伍记录、状态机和队长权限另审 |
| 公告与赞助 | 公告草稿、已发布内容和公开赞助展示。旧管理及登记拒绝 | 独立角色、审核、CSP 和最小权限 |
| profile-lab 和 session-lab | 头像演示用本机存储与合成身份。会话端点只接受获批本机合成目标 | 正式头像与真实会话分批，实验标识保留 |
| 招募表单 | 公共入会联系仍使用外部邮件服务，和已暂停的成员写入不同。本轮浏览器复测拦截外部请求 | 招募交付依旧独立于认证和成员写入 |

未接入的旧签到、积分排行、攻略墙等组件仍含历史缓存处理。正式恢复前按此表重新核对它们的引入路径，避免把旧客户端身份接入新入口。后端闭锁由 API、安全和合成 PG 测试验证。真实资源的权限与会话有效性由各自 TEST 门槛验证。
