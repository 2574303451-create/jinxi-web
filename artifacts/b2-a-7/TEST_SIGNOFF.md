数据库管理员可从仓库运行 `node artifacts/b2-a-5/test-role-evidence.cjs --sql` 生成只读 SQL。按 T04 的授权在独立 TEST 会话运行，并将脱敏 JSON 与已审核 policy 交给 `--verify proof.json expected-test-policy.json`。运行时检查覆盖数据库身份和直接 ACL，间接权限继续由 F05 验证。 [A5 操作示例](../b2-a-5/TEST_GATE.md)

验收负责人按 T06–T07 采集所批准页面的公开响应头与静态 HTML，在隔离工作区运行 `node artifacts/b2-a-6/verify-hosted-csp.cjs csp-manifest.json evidence.json`。手工核对捕获的 SHA 与 deploy ID 对应 T01。额外的 404、静态 MIME、压缩缓存和 Functions 错误头在表内登记。采集材料只保留批准的公开头和必要静态字节，凭据与 Cookie 值不进入表。

任一必填证据或授权缺失即暂停对应执行阶段。TEST 失败时由管理员冻结候选部署、撤销专用权限、恢复隔离快照，记录失败及复测编号。F08 与 T09 是两个独立审批节点，配置字段只记录已经完成的决定。
