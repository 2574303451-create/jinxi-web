# 旧业务恢复顺序

恢复以 [A-4 的 16 项入口清单](../b2-a-4/RESTORATION_MATRIX.md) 为依据。每批先在独立 TEST 申请权限和执行带回滚演练，通过后另行授权。已暂停的旧接口持续拒绝。页面使用服务端会话和稳定 member ID。工号只限私有映射，昵称只用于公开显示。原页面保留阅读、历史参考和可恢复的本机草稿。

| 批次与依赖 | 身份与权限 | 数据迁移 | TEST 验收、失败恢复与回滚 |
| --- | --- | --- | --- |
| 1 · 登录、资料读取、改密。依赖云隔离与备份 | 登录校验账户与有效档案。服务端会话派生主体，资料按字段白名单输出。改密验证当前密码、CSRF 与 Origin，撤销该成员所有设备会话 | 先核对真实 TEST 的映射、约束、密码格式及迁移历史。以事务演练 [A-4 会话草案](../b2-a-4/MEMBER_SESSION_PLAN.md)，独立摘要/过期/撤销表，最小角色 | 两成员尝试互读、互改以及改密与登录并发。首次强制改密、停用、过期、多标签/多设备、401/403/429/503、草稿保存。旧缓存不可驱动正式账户菜单。失败时恢复旧 UI 的暂停态，撤销会话及权限，备份后回滚新会话表 |
| 2 · 成员留言、回复、反应、攻略投稿与评论。依赖 1 | 会话成员本人编辑，管理员由服务端角色验证。长度、频率、Origin、审核与媒体校验。游客另设匿名策略及审核，游客署名独立展示 | 加可空作者 ID 外键并保留历史署名。禁止按昵称回填。反应唯一约束按成员与内容，投稿/评论有版本和审核状态 | 两人同昵称隔离、跨账号改删、伪造作者、双标签并发反应、重复请求、失败保存草稿。匿名及新成员头像框、留言回复、双行展播和独立攻略回归。先验证公开 DTO 中无稳定内部 ID、私有收藏和未经审核字段。停写/撤销新授权并保留新数据快照，回到安全只读 |
| 3 · 签到、每日任务、积分奖励和兑换。依赖 1 与相应服务端事实 | 会话主体、服务端任务完成事实、规则版本及商品目录。请求不接受身份、积分增量或价格。事务锁余额，禁止负数 | 有约束的流水和余额、日期规则唯一键、每成员每订单键、可信收据与恢复查询。迁移核对来源，旧浏览器历史积分保持参考 | 价格和奖励篡改、跨账号收据、并发余额、双领、防刷、目录改变。丢响应后跨刷新/设备查询原收据，确认结果再发起新订单。失败事务回滚，停止发放和兑换时保留不可变流水。UI 显示规则参考值、暂停态及可核验的失败 |
| 4 · 组队、公告管理、赞助、排行榜等。依赖 1，榜单奖励依赖 3 | 队长/成员的状态转换权限、公告最小管理员、赞助审批和字段约束。排行榜只输出允许公开的聚合字段 | 成员 ID 外键、状态机、并发唯一约束、审计与发布历史。公告继续白名单和 CSP。赞助敏感字段隔离。榜单计算与发布有版本 | 跨账号申请、重复加入、同时审批、恶意 HTML/媒体、榜单字段泄漏。保留本机演示和可见暂停态。出错时冻结写入及榜单发布，切回只读快照，恢复上一批准公告版本 |

旧攻略完整 DTO 仍带旧 likes、favorites、comments 数组。恢复第 2 批前先给公开读取建立最小投影，使用合成哨兵值测试账号、内部 ID 与私有收藏不会通过任何首页、列表、详情契约泄漏。原有公开计数和合法署名继续可读。

头像与在线继续按 [B2-C+ 规格](../b2-0/B2C_PLUS_PLAN.md) 等待独立授权。图片仅填充原头像框。在线需要有效服务端会话和心跳，按稳定成员 ID 去重。首页统计卡片保留 —，后续成员可点击打开右侧抽屉。名单需登录，个人可见性默认关闭，绿点静态，不输出工号、账号、IP 或会话资料。
