# B2-C+ 后续规格（本轮不实施）

这是用户对B2-C的补充，不替代B2-0/B2-A检查点，也不提前启用心跳、在线名单或生产头像。当前首页在线保持—。原方案中“只公开人数”继续适用于游客；新名单仅向服务器已认证成员提供，不能向游客先返回再隐藏。

- 在线总数：有效服务器会话、成员活跃/未锁定、窗口内有效心跳，COUNT DISTINCT稳定成员ID，多标签/多设备合并；不信任昵称、localStorage或客户端memberId。
- 名单：成员隐私开关默认关闭，主动开启且在线才进入。关闭后尽快撤出；总在线数X与可展示数Y分开。仅返回不透明公开ID、昵称、已安全处理的头像URL/文字回退、在线布尔与统计时间。不返回账号、工号、IP、设备、会话或精确最后活动时间；历史同昵称游客不关联。
- 接口建议逻辑presence/roster，实际Netlify映射须验证。未认证在服务端拒绝。稳定排序、有界分页、错误非0/非假名单；只在抽屉打开且前台时有限刷新，关闭/后台取消，共享并发，不新建重复心跳。
- 右侧“在线公会伙伴”dialog抽屉：X人在线·Y人公开展示；现有纸张/2px黑边/硬影/蓝黄体系，绿色点静态，现有头像框不改。桌面380–420px，320/390手机宽度不越界；只列表滚动，安全区、可见关闭、遮罩/Escape关闭、背景锁滚、焦点圈定并返回触发点。180–240ms transform仅开关时；reduce取消位移，不加动画库。
- 60秒心跳/180秒租约/15秒缓存仅为待测参数。绿色表示窗口内有心跳，不证明此刻仍在浏览。区分无人在线、有人在线无人展示、加载、失效登录、服务器/网络故障、头像失败。
- 后续验收：未登录/同昵称不同ID/多标签多设备/锁定停用退出过期/超时断网恢复后台/成员ID篡改/高频及参数、隐私开关、320/390/768/1440、键盘/读屏/reduce、性能比较和回滚。只用明确合成数据。

顺序：B2-0隔离→B2-A可信会话安全验收→B2-B头像（可与抽屉UI独立）→B2-C真实人数、隐私设置、成员API、抽屉、隐私/性能验收。未单独批准，不生产迁移/合并/发布。本轮不制作静态名单，避免合成成员被误认作实时在线。
