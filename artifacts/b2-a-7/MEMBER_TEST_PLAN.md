# 真实成员 TEST 接入顺序

[管理员验收表](TEST_SIGNOFF.md) 的 T09 通过后，由负责人批准独立成员 TEST 候选。第一批限于登录、本人资料查询、修改密码和退出登录。先用授权合成账户验证失败路径，再按单独批准的成员范围验收。现有 `session-lab` 继续使用专用本机合成身份和权限。

| 验收项 | 数据库管理员提供的脱敏记录 |
| --- | --- |
| `guild_member_accounts` | schema、列类型、主键、账号唯一约束、有效/锁定权威字段、首次改密标记、散列格式的聚合统计、RLS、触发器、所有者与迁移版本 |
| `guild_member_profiles` | schema、稳定且不可变的 member ID、主外键、停用字段、可公开与私有列、授权来源和规则 |
| 账号到成员映射 | 账号与档案关系的约束及聚合核对。记录重复、空值、断链、冲突与人工修复方案 |
| 版本与恢复 | 真实 TEST 库身份、备份与隔离恢复编号、恢复点、DDL 审查和回滚顺序 |
| 208 份公会档案 | 这是仓库展示的历史档案数量。活跃账号、有效成员和在线人数各用其独立数据来源核验。历史署名继续独立显示 |

在获批系统内验证散列算法、参数、解析与首登要求，只输出格式分类和聚合结果。遇到未识别算法、来源不明记录或不完整映射先停止导入。私有映射以受信导入及外键为准，同名不构成认领条件。核对真实表结构后再从 [会话草案](../b2-a-4/MEMBER_SESSION_PLAN.md) 设计 DDL 迁移。

## 一个服务端会话状态

未来的 `GET session` 从安全 Cookie 查会话摘要，再查稳定 member ID、账户状态、资料状态、过期和撤销。仅返回最小 DTO 和允许的会话状态。公开资料的引用应独立于工号、登录名、设备、密码元数据及令牌。私有本人资料按服务器授权取最小字段。

| 前端统一状态 | 导航与功能边界 |
| --- | --- |
| 检查中 | 等待服务器结果。会话要求的操作保持关闭，公开页面和本机草稿可用 |
| 游客 | 公开读取和本机参考。显示登录入口 |
| 需要改密 | 仅本人首次改密、退出及必要提示。改密后撤销旧会话并重新登录 |
| 已认证 | 由同一会话查询结果显示本人资料。第一批只开资料、改密和退出 |
| 核验不可用 | 显示重试。保留草稿，阻断依赖会话的操作 |

登录、资料、改密和退出使用同一个会话读取层。正式接入替换旧缓存认证逻辑，旧入口继续禁用。退出、改密、过期、锁定或停用时让各页面重新向服务端核验。多标签只传递需要刷新状态的提示。跨设备、账户权限与所有写操作由服务端逐次判定。

现有首页、留言、攻略、任务及本机演示的入口核对见 [身份审计](IDENTITY_AUDIT.md)。旧 localStorage 保留已标明来源的本机记录和草稿。服务端取提交作者，前端头像、昵称和账号文本只用于展示。待恢复的公告、赞助、排行、组队和积分接口延用各自授权门槛。

## 依次验证四项业务

| 操作 | 服务器约束 | 实际 TEST 验收 |
| --- | --- | --- |
| 登录 | 统一错误和限流，验证锁定、停用及散列兼容。服务端生成不可猜测令牌，数据库仅保存摘要。Cookie 使用 Secure、HttpOnly、SameSite 和受限范围 | 正常、错误密码、未知账号、锁定、停用、首登强制改密、并发登录、多设备和多标签 |
| 本人资料 | 从会话取主体。严格白名单投影、无缓存，拒绝跨账号查询 | 修改 ID/参数无效，匿名和失效会话拒绝，响应排除账号凭据及私有字段 |
| 改密 | 验证本人的当前密码、CSRF 和 Origin。在同一事务内更新密码版本并撤销旧会话 | 跨账号改密、旧 cookie 重放、两设备并发、冲突事务、失败回滚和重登 |
| 退出 | 幂等撤销当前会话，清除 Cookie。处理断网导致的未确认退出 | 同令牌再次请求拒绝，撤销失败可重试，另一个独立设备按其会话状态核验 |

盗用防护测试覆盖前端无法读取 HttpOnly Cookie、错误来源或缺少 CSRF、会话固定、绝对与闲置超时、过期/已撤销 cookie 重放，以及敏感数据不出现在 URL 或日志。被盗的有效令牌按撤销和时限策略处置。核对故障期间的状态与清理，不因网络故障恢复已撤销身份。

只在对应 TEST 审批范围保存测试结果，证据包含脱敏请求编号、部署 SHA、规则版本和预期/实际。失败时关闭第一批候选入口、撤销其会话和运行角色、按隔离恢复记录复原新表。现有只读和本机草稿继续可用，生产迁移和发布各有独立审批。
